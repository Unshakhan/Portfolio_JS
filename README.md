# Unsha Sattar — Personal Portfolio

My personal portfolio showcasing my development skills, experience, certificates and projects.

Built with HTML, CSS and vanilla JavaScript, with a plum and champagne theme and support for both dark and light modes.

## Features

- Responsive layout for mobile, tablet and desktop
- Navigation with active section highlighting
- Dark and light theme toggle
- Animated introduction and typing effect
- About Me and Skills sections
- Experience and Certificates tabs
- Certificate image previews
- Project showcase
- Contact form that opens a pre-filled email draft
- GitHub, LinkedIn and CV links
- Scroll-to-top button
- Subtle starfield, portrait glow and cursor effects
- Keyboard navigation and reduced-motion support

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

CSS custom properties manage the theme colors, spacing and animation timing.

## Getting Started

1. Download and extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

No installation or build step is required.

## Project Structure

- `index.html` — Page structure and content
- `styles.css` — Theme, components and responsive styles
- `stars.css` — Animated star background
- `script.js` — Navigation, tabs and page interactions
- `theme.js` — Saved theme preference
- `loader.js` — Opening loading animation
- `assets/` — Images, icons, certificates and CV

## Contact Form

The contact form validates the entered information and opens
the visitor’s email application with a pre-filled message.
The visitor must send the email from that application.

## Customization

Update the content in `index.html` and replace the relevant
files in `assets/` to change the profile image, CV and certificates.

Theme colors can be adjusted through the CSS custom properties.

Some project cards, certificate images and skill ratings are
placeholders and will be replaced with final content.
